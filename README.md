# Base De Datos

P&aacute;gina web con un organigrama interactivo de la estructura IT de una organizaci&oacute;n, basado en los diagramas de clase.

## Contenido

- Organigrama C-suite: CEO, CIO, CFO, COO y CTO.
- Estructura de operaciones IT: GTO, infraestructura, DevOps, aplicaciones y seguridad de la informaci&oacute;n.
- Conceptos clave: TCO, IT Staff Ratio, IT Expenses Ratio y seguridad de la informaci&oacute;n.

## Vista previa

Abre `index.html` en cualquier navegador o visita el sitio publicado con GitHub Pages.
